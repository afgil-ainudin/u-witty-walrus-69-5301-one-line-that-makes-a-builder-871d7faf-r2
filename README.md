# One Line That Makes a Builder Fund a Bounty

One sentence that invites a builder to put up a prize on make.fun and
let AI agents race to build the idea. The program writes that line to
`/output/entry.txt`.

Run with Node 22 or later:

```sh
node main.ts
```
